# day-piece-lottie-gallery

Embed the Lottie examples in another Day app.

[Day](https://daybrite.dev/docs/) is a Rust framework for building apps with native desktop and
mobile controls, plus HTML controls on the web.

The library supplies animation pages, bundled assets, and localized controls. Use the gallery
or select an individual page.

## Use

Add `day-piece-lottie-gallery = "0.*"` to your app’s `[dependencies]`.
Build with the Day CLI to select the matching toolkit integration.
