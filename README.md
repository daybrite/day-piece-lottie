# day-piece-lottie

Play bundled Lottie animations in a Day interface.

[Day](https://daybrite.dev/docs/) is a Rust framework for building apps with native desktop and
mobile controls, plus HTML controls on the web.

Use generated asset constants and control animation selection and speed with signals. Rendering uses
the platform integration; supported animation features and dynamic controls vary by engine.

## Use

Add `day-piece-lottie = "0.*"` to your app’s `[dependencies]`.
Build with the Day CLI to select the matching toolkit integration.
